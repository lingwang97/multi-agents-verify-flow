# docs/reports

Verification campaign reports, written through the multi-agent flow.

- **Naming**: `<YYYY-MM-DD>_<dut>_<scope>_report.md` (e.g. `2026-12-05_<dut>_block_report.md`).
- **When**: at campaign milestones — convergence/sign-off, or a user-designated point.
- **How**: the leader compiles the report from agent outputs per the section→agent map in `report_template.md`; each section cites its producing agent; pointers over prose wherever a canon exists (`docs/modules/`, `docs/features/`, `docs/review/`, `deliver_bridge/`).
- **Append-only**: one report per campaign/attempt, never rewritten; corrections land as a dated addendum inside the affected report or as a new report.
- **Template**: `report_template.md` (the outline every report follows).
